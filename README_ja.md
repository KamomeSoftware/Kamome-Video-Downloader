# Kamome Video Downloader

**Kamome Software** が開発する、yt-dlp向けのシンプルなWindowsポータブルGUIです。

## 主な機能

- URL貼り付け後に動画情報を自動解析
- サムネイル、タイトル、投稿者、長さをプレビュー
- 解像度 / FPS / コーデック / 推定容量から形式を選択
- MP4ダウンロードとメタデータ埋め込み
- サムネイル埋め込み時も画像ファイルを保持
- Firefox / Chrome / Edge Cookie対応
- 日本語 / English UI
- yt-dlpの自動更新確認
- GitHub Releasesによるアプリ本体の更新確認
- 前回終了時のウィンドウサイズ・位置・最大化状態を復元

## ポータブル版

インストール不要です。Release ZIPを展開し、`KamomeVideoDownloader.exe` を実行してください。
Kamome自身の設定はAppDataやレジストリではなく、実行ファイルと同じ場所の `settings.json` に保存します。
